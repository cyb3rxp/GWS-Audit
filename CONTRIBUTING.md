# Contributing to GWS Audit

Thank you for your interest in contributing to GWS-Audit.

This project and tool aim at providing an holistic security configuration assessment of a Google Workspace instance, with no dependency to any security vendor.

Contributions are welcome and appreciated.

---

# How to Contribute

You can contribute by:

- Adding new resources
- Suggesting code improvements
- Identifying security vulnerabilities in the code, plus their remediation
- Improving descriptions
- Fixing broken links
- Improving structure or formatting
- Suggesting new sections

Please open a Pull Request (PR) with your proposed changes.

---

# Contribution Guidelines

To keep the list useful and high-quality, please follow these rules.

## 1. Quality resources only

Resources should be:

- Relevant to SecOps operations related to security assessments of Google Workspace
- Technically valuable
- Maintained or widely used
- Not purely promotional

Avoid:

- Marketing pages/speech
- Low-quality blog spam
- Affiliate links

---

## 2. Add a short description

Each resource must include a short description explaining why it is useful.

Example:

Good:

- Reporting — Added HTML expandable lists

Bad:

- Reporting change

---

## 3. Place resources in the correct section

Before adding a new section, check if the resource fits in an existing one.

If you believe a new category is needed, explain it in the PR.

---

## 4. Keep descriptions concise

Descriptions should be one sentence.

Example:

Correct:

- Reporting — Added expandable lists in the HTML output file

Avoid long explanations.

---

## 5. Alphabetical order

When possible, add resources in alphabetical order within a section.

This keeps the list easy to maintain.

---

# Pull Request Process

1. Fork the repository
2. Create a new branch
3. Add your changes
4. Open a Pull Request
5. Explain briefly what you added or changed

Example PR title:

- Reporting — Expandable lists

---

# Code of Conduct

Please be respectful and constructive in discussions.

---

# Thank You

Your contributions help make this repository a useful reference for the SOC/CSRT and audit community.
